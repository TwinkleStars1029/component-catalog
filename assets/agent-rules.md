## 做畫面（UI）時

1. **先讀元件總表 `<總表路徑，例如 src/ui/CATALOG.md>`。** 它列出每個物件（頭像、分隔線、空狀態…）在每個風格各有哪一份程式，以及目前用在哪裡。
2. 要畫這些物件時，用現成的元件（`<取用方式，例如 const { Avatar } = useVariant();>`）。不要在頁面裡另外畫一份，也不要在頁面裡寫「如果是某風格就…」的判斷。
3. 總表標「還沒有地方使用」的物件，是已經做好、等著放進畫面的素材。新畫面有合適的位置就用上。
4. 找不到合適的物件：先問使用者，不要自己新增物件，也不要在頁面裡寫某個風格專屬的樣式。
5. 說「設計稿沒畫」之前，先把設計稿（`<設計稿位置>`）裡所有相關畫面都查過一遍。

## 改了元件之後

新增、刪除或改名物件，新增風格，或改了頁面裡元件的用法，都要重新產生總表：

```
<產生指令，例如 npm run catalog>
```

沒重新產生，`<檢查指令，例如 npm test>` 會失敗。新增物件時，也要在 `component-catalog.config.json` 補上中文名稱與用途。
